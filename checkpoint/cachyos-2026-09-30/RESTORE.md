# Restore this configuration on fresh CachyOS/Arch

This is a forensic checkpoint of the desktop as captured on 2026-09-30, not an installer. Read `WIP_STATE.md`, `MACHINE_ASSUMPTIONS.md`, `docs/THEME_PIPELINE.md`, and `docs/INVENTORY.md` first. The `home/` and `system/` trees contain source or intentionally preserved configuration. `generated-reference/` contains known-good generated output, **not** canonical source. `FILE_MANIFEST.tsv` maps every payload file to its original path, SHA-256, mode, symlink target and restoration destination. For symlinks, its SHA-256 hashes the UTF-8 link-target string, since symlinks have no file payload of their own. Run commands here only on the fresh installation after reviewing them for the new account and hardware.

## 1. Prerequisites

Install CachyOS/Arch with a working network and a user account. Confirm the intended home path, monitor name, audio sink, keyboard LED, and filesystem paths.
