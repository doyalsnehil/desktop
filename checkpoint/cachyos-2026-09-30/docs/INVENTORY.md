# Discovery inventory and exclusions

Shallow read-only discovery covered home top-level entries, `~/.config/`, `~/.local/`, referenced system locations, and active references from Hyprland, Waybar, Quickshell, Matugen, Ghostty, scripts, and systemd. `FILE_MANIFEST.tsv` records the actual restoration payload. The classifications below explain decisions on areas omitted from that payload.

| Area | Classification | Decision |
|---|---|---|
| Zsh, Bash, GTK 2 dotfiles; active Hyprland Lua tree; personal Quickshell tree; Waybar source; Matugen templates; Ghostty source; Fuzzel; personal scripts; Neovim source and lockfile | PRESERVE EXACTLY | Original paths and modes in `home/`; Quickshell and Hyprland recovery copies are retained as historical files but active files are primary. No live files were modified. |
| MPV config, uosc script source, script options and fonts; Alacritty, Kitty, btop, fish, micro, MarkText preferences, swash, Noctalia config, KDE/Qt/XDG settings, menu settings | PRESERVE EXACTLY | Useful small settings. MPV's uosc v5.12.0 Linux helper binary is reconstructable from its upstream release; foreign-platform binaries are excluded. |
| Git identity, VS Code telemetry ID, Fast.com speedtest token-like constant, bundled uosc OpenSubtitles API key | PRESERVE SANITIZED | `gitconfig.template`, `argv.template.json`, `personal-network-speedtest`, and MPV `scripts/uosc/main.lua` use `<SET_LOCALLY>` placeholders. See RESTORE. Exact original values are not in the checkpoint. |
| Matugen palette, Waybar colors, Ghostty theme, GTK/Qt Noctalia colors | GENERATED REFERENCE | Known-good outputs in `generated-reference/`, separate from editable templates. |
| Pacman explicit native/foreign/versions, complete installed names, Flatpak apps, global npm, Cargo/uv, VS Code extensions, enabled services, dev-tool versions | MANIFEST ONLY | Installed binaries, package databases, extensions and caches are not copied. |
| `~/.config/Code - OSS/User/{globalStorage,workspaceStorage}` and other Electron app state; browser profiles; RustDesk configuration/peers; `~/.config/Antigravity`, `Codex`, `configstore`, `dconf`, `pulse/cookie` | EXCLUDE — PRIVATE/RUNTIME | Likely auth, histories, local identifiers, chat or cookie state. Code - OSS had no substantive `settings.json`, `keybindings.json`, or snippets to preserve. |
| `~/.ssh`, `~/.gnupg`, `.npmrc`, `.codex`, `.copilot`, `.gemini`, keyrings, shell history, viminfo, trash, recent-files state, `.local/state` | EXCLUDE — PRIVATE/RUNTIME | Private backup checklist covers intentional private copies. Wallpaper state is documented by path and hash, not copied. |
| `~/buildScripts/{codex-desktop,marktext}/PKGBUILD` | PRESERVE EXACTLY | Hand-written package recipes; the large `.deb` and `.pkg.tar.zst` inputs/outputs are excluded. |
| `~/.cache`, `.local/share/nvim`, `.local/share/npm`, `.rustup`, `.cargo` installations, VS Code extension packages, MPV uosc vendor executables, `~/.local/bin/agy`, build packages under `~/buildScripts` | EXCLUDE — CACHE/VENDOR | Reinstall using manifests or upstream sources; no binary bundle or build output in public Git. |
| `~/.config/cachyos`, `yay`, `session`, `nautilus`, `mozilla`, `zen`, `net.imput.helium`, `rustdesk`, `marktext` runtime parts, `swash` runtime parts, `~/.config/quickshell/shell.qml` legacy default shell | EXCLUDE — RUNTIME/IRRELEVANT | These are package state, app profiles, or inactive roots; the active `personal/` tree is preserved. |
| `/usr/share/wayland-sessions/{hyprland,hyprland-uwsm}.desktop` | MANIFEST ONLY | Package-owned entries; RESTORE records which was used and its Exec path. |
| `/etc/sudoers.d/10-installer` | MANIFEST ONLY — INSTALLER GENERATED | The user listed the root-only directory and confirmed this is its sole entry. [Calamares' users module](https://github.com/calamares/calamares/blob/calamares/src/modules/users/users.conf) documents this exact generated filename. `pacman -Qo` reports no package owner, consistent with installer creation. No `personal-dns` or `personal-dev-path` rule exists there. Contents were not read, so local edits inside `10-installer` cannot be ruled out from filename evidence alone; no custom desktop/DNS rule is indicated. Recreate sudo access through the fresh installer. |

Potentially useful private data such as documents, unpushed repositories, browser profiles, or game saves is outside this **configuration** checkpoint. See `PRIVATE_BACKUP_CHECKLIST.md`.

`~/.config/awww/`, `~/.config/swayosd/`, and `~/.config/systemd/user/` did not exist. The awww daemon and SwayOSD server are launched by Hyprland autostart. The root-run personal audio router unit and executable are preserved. `/etc/NetworkManager/conf.d/20-omarchy-dns.conf` and `/etc/systemd/resolved.conf` are copied as evidence; do not assume the DNS switcher works.
