# Package and service interpretation

`manifests/pacman-explicit-native.txt` is the native explicitly installed set; `aur-foreign.txt` is the foreign/AUR set; `pacman-explicit-versions.txt` records versions for both. `pacman-all-names-reference.txt` is the complete installed-name reference, including dependencies. It is deliberately **not** the recommended install list. The Flatpak manifest contains Blanket and Stremio. npm global contained `@openai/codex@0.158.0`; uv and Cargo tool lists were empty. The Code extension directory list was empty. `dev-tool-versions.txt` and `go-version.txt` record installed CLI versions.

Desktop packages to prioritize when rebuilding: Hyprland, Quickshell, Waybar, Matugen, awww, Ghostty, Fuzzel, SwayOSD, SDDM plus astronaut theme, NetworkManager, BlueZ, PipeWire/WirePlumber, UPower, power-profiles-daemon, brightnessctl, evtest, grim, slurp, curl, jq and iw. Appearance and shell dependencies are detailed in RESTORE. The installed package manifests are evidence of state, not a claim that every package is necessary.

SDDM was the enabled active display manager. Plain Hyprland was the active Wayland session, using the package-owned `hyprland.desktop` entry and `/usr/bin/start-hyprland`; UWSM had a separate installed entry. `greetd.service` and `swayosd-libinput-backend.service` were disabled. Hyprland autostart launched `awww-daemon`, `personal-wallpaper`, `personal-kbd-osd-daemon`, `swayosd-server`, Waybar and `qs -p ~/.config/quickshell/personal`. The active `personal-audio-router.service` was system-managed, with an executable preserved under `system/usr/local/bin/`. Enabled unit snapshots are in `manifests/systemd-*.txt`; no services were changed for this checkpoint.

The SDDM autologin config names the old account, so review it before restoring. System DNS evidence includes `20-omarchy-dns.conf` and `resolved.conf`; these do not prove the personal DNS helper works. The user listed `/etc/sudoers.d/` and found only `10-installer`, the filename [Calamares documents for its generated sudoers file](https://github.com/calamares/calamares/blob/calamares/src/modules/users/users.conf). It is installer-owned state by classification, not a captured desktop/DNS customization. Its contents were not read.
